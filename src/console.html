ZCode Pipeline Console

inject → claim Start Plan → connect 9Router

1 · Inject idle

Mint a ZCode JWT from a z.ai session. Paste a bearer token or a cookies string (or export).

Writes the JWT to outputs/…/console_inject.json and prints it in the log.

2 · Claim Start Plan idle

Needs the Aliyun captchaVerifyParam. Solve the slider in the z.ai tab (the tab next to this one), then copy the param here. Tip: the param is a long base64 blob.

Paste the param right after solving — it is single-use and short-lived.

3 · Connect 9Router idle

Register the claimed account as a glm provider connection in 9Router.

Uses the JWT file above, or re-mints from the token/cookies on the left.

Captcha solver tab
